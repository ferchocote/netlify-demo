# Demo de cartilla interactiva

Paquete estático para desplegar en Netlify. Incluye únicamente la versión responsive del demo; no contiene cotizaciones, PDFs ni archivos temporales del proyecto.

## Despliegue

- Repositorio sugerido: `cartilla-interactiva-demo`.
- Directorio de publicación: raíz del repositorio (`.`).
- Comando de build: ninguno; es un HTML autocontenido.
- El sitio se puede servir desde Netlify con HTTPS.

## Datos de demostración

La experiencia conserva el progreso y los datos que se ingresen en el almacenamiento local del navegador. No hay backend ni sincronización con un servidor. Usa datos ficticios y no ingreses información personal real en esta demo.
